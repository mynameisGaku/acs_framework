# Compat

**ACS 配布物の世代差を吸収する唯一の場所。**

このファイルは**フォルダに何を置いてよいか**を決めるもの。迷ったらここに戻ること。

---

## なぜ要るのか

枠組みの本体は、ある時期の ACS に在った API を前提に書かれていた。手元の配布物
(2026-08-03 生成) にはそれが無く、**プロジェクト全体がビルドできない**状態が続いていた。

ただし調べてみると、無いのは機能ではなく**名前**だった。

| 枠組みが呼んでいたもの | 2026-08-03 配布物での実体 |
|---|---|
| `UiFontDefaults::TryLoad(...)` | `acs::FSample::TryLoadDefaultUIFont(...)` — **引数も戻り値も同一** |
| `ACS_ENUM()` | 印だけのマクロ。この配布物は知らないので畳む |
| `acs::EnumNames<T>()` / `EnumCount<T>` / `EnumToIndex` / `EnumFromIndex` / `IsValidEnum` / `ToString` | 同等品が無い (在るのは `ACS_REGISTER_ENUM` による登録制の実行時反映) |

そこで、**使う側は `AcsFw::` の口だけを見る**ようにした。配布物が変わっても、
書き換えるのはこのフォルダの中だけで済む。

---

## フォルダに置いてよいもの

| 置き場所 | 置いてよいもの |
|---|---|
| `AcsEnumReflection.h` | 列挙型から名前・個数・位置を引く口 |
| `AcsUiFont.h` | OS の既定 UI フォントを読み込む口 |
| `AcsAnnotations.h` | 印だけのマクロ (`ACS_ENUM`) |

**ここに «便利関数» を置かない。** 置いてよいのは「配布物によって在ったり無かったりするもの」
だけ。どの配布物にも在るものを包むと、ただの遠回りになる。

---

## 対応する配布物へ移るとき

切り替えは**スイッチ 1 つずつ**。使う側の変更は要らない。

| スイッチ | 既定 | 0 にすると |
|---|---|---|
| `ACSFW_USE_ACS_ENUM_REFLECTION` | **1** (エンジンの `foundation/EnumTraits.h`) | このヘッダが `__FUNCSIG__` から自前で引く |
| `ACSFW_USE_ACS_UI_FONT_DEFAULTS` | **1** (`UiFontDefaults::TryLoad`) | `acs::FSample::TryLoadDefaultUIFont` を呼ぶ |

**既定はどちらもエンジン側。** 追っている配布物 (ACS の `dev`) には両方在るので、根本の機能は
エンジンに任せる。0 の側は、それらを持たない古い配布物 (2026-08-03 生成など) 用の逃げ道。

`ACS_ENUM` は自動。エンジンが定義していればそちらが勝つ (`#if !defined` で守ってある)。

どちらの側も自己テストが通ることを確認してある (`Source/Common/Test/EnumReflectionTest.cpp`)。

**見つからないときの値はエンジンに合わせてある。** `EnumToIndex` は `kInvalidEnumIndex`
(= `SIZE_MAX`) を返す。0 を返すと «先頭が選ばれている» と区別が付かず、壊れた値が黙って
先頭の選択肢として通ってしまう。自前実装も当初 0 を返していたが、テストが食い違いを捕まえた。

## 列挙の名前をどう引いているか

コンパイラが出す関数名 (`__FUNCSIG__`) に型引数がそのまま入ることを使う。
`EFoo::Bar` と出れば列挙子、`(enum EFoo)0x5` と括弧付きで出れば列挙子ではない。
これを 0 から順に調べて名前表を作る。**すべてコンパイル時に終わる**ので実行時の costs は無い。

**限界: 0 以上 64 未満の値しか見つからない。** 負の値や大きな値を持つ列挙型を画面へ出すと、
その列挙子は黙って選択肢から消える。枠組みが扱う列挙型はすべて 0 から連番なので足りている。
上限を変えるなら `AcsFwEnumDetail::kScanLimit`。

MSVC 専用。`__FUNCSIG__` の書式に依存しているので、**自己テストで毎回確かめている**
(`Source/Common/Test/EnumReflectionTest.cpp`)。名前が引けなくなれば、そこが最初に落ちる。
