# Models

`.fbx` を置く。

## 書き出すときに合わせること

| | |
|---|---|
| 単位 | メートル。1 が 1 m |
| 上 | +Y |
| 前 | +Z |
| 三角形化 | 書き出し側でやっておく (読み込み側でもやるが、意図した割り方が残る) |

**単位がずれるといちばん困る。** センチメートルで書き出すと 100 倍の大きさで置かれ、
カメラも影も遮蔽もその大きさに引きずられる。「置いたのに何も見えない」の典型。

## 大きさが合わないとき

`FModel3DSpawnParams::Scale` で直せるが、**書き出し側を直す方がよい**。
`Scale` で辻褄を合わせると、当たり判定・影・遮蔽の半径が全部ずれたままになる。

## 入っているもの

| | 出どころ |
|---|---|
| `MergedSphere.fbx` | Effekseer 同梱のサンプル (`ThirdParty/Effekseer/ResourceData/samples/00_MaterialBasic/Models`)。**取り込みが通ることを確かめるためだけ**に置いてある |

## 真っ黒になったら法線を疑う

取り込んだモデルが**色を付けたのに暗い灰色**なら、たいてい法線が裏を向いている。
片面だけの薄い板 (旗・草・エフェクト用の形) でよく起きる。

- 書き出す前に法線を再計算する
- 片面のものは、両面に描くか、板を二重にする

最初この置き場には Effekseer の `Arrow.fbx` を入れていたが、片面の薄い扇形なので
このデモの画角では裏面しか見えず、何を置いても暗いままだった。閉じた形に差し替えてある。
